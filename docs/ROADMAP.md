# 分阶段路线图

## 总原则

全局治理属于高影响基础设施。每个阶段必须独立验收，后续阶段不能依赖未经验证的前置成果。

## 阶段 0：环境与风险基线

状态：完成。

交付物：

- 只读确认现有全局 `AGENTS.md`、配置和插件市场状态。
- 确认源码目录与运行目录分离。
- 确认安装不能覆盖现有 `config.toml`。

门禁：

- 未产生任何全局写入。

## 阶段 1：治理源码骨架

状态：完成。

交付物：

- 维护者 `AGENTS.md`。
- 全局治理内核草案。
- 插件 manifest。
- 四个聚焦 Skill 及按需 references。
- 架构、ADR、风险登记和当前状态。

门禁：

- Plugin 和全部 Skill 通过官方校验器。
- 不存在占位符或失效相对引用。
- Git diff 仅位于本仓库。
- 全局目录保持不变。

验收记录：

- Plugin 官方校验器通过。
- 四个 Skill 官方校验器全部通过。
- 占位符、尾随空白、相对引用、JSON/YAML 解析检查通过。
- 全局 `AGENTS.md` 保持 0 字节，未创建个人 marketplace。

## 阶段 2：项目契约与确定性工具

状态：完成。

交付物：

- 版本化的项目契约 schema。
- 适配已有项目的最小模板。
- 初始化、审计和结构检查脚本。
- 隔离临时目录中的脚本测试。

门禁：

- 初始化幂等。
- 默认不覆盖已有文件。
- 失败时不留下半安装状态。
- 对 Lite、Standard、Assured 和已有复杂项目均有测试。

验收记录：

- `.harness/project.json` schema 与标准库验证器通过一致性检查。
- 初始化工具默认 dry-run，显式 `--apply` 才写入。
- 重复初始化返回 `unchanged`，不改动已有内容。
- 已有 `AGENTS.md` 和项目事实来源保持原样。
- 故障注入证明部分文件与本次新建目录均会回滚。
- Lite、Standard、Assured、路径逃逸、跨平台绝对路径、契约冲突和只读审计共 12 项测试通过。
- Python 3.9 目标的静态检查、格式、编译、源码结构与官方 Plugin/Skill 校验通过。

## 阶段 3：评测与安装 dry-run

状态：完成。

交付物：

- 代表性任务集与基线。
- 上下文重量、错误完成、干预次数和恢复能力指标。
- 安装、状态、doctor、回退和卸载工具。
- 使用隔离 `CODEX_HOME` 的端到端测试。

门禁：

- 新旧行为可比较。
- 安装 dry-run 显示精确差异。
- 备份和回退经过实际演练。
- 不依赖真实用户全局目录完成测试。

验收记录：

- 可安装包与维护仓库分离，安装缓存只含 24 个运行时文件。
- 使用真实 Codex CLI 在临时 `HOME` 与 `CODEX_HOME` 中完成 marketplace 添加、Plugin 安装、状态检查、doctor、重复安装、卸载和 marketplace 移除。
- dry-run 零写入；故障注入证明全局规则和 marketplace 会回滚。
- 卸载精确恢复原 `AGENTS.md`，且保留受管区块之外的后续用户编辑。
- 12 个路由案例中，基线完全正确率 75%、字段准确率 85.4%；Treatment 两轮均为 100%。
- Treatment 平均输入增加 1,413 tokens，低于 1,800 tokens 门禁。
- 20 项自动化测试全部通过。

## 阶段 4：受控安装

状态：完成。

步骤：

1. 展示待安装版本、托管区块和配置差异。
2. 备份相关全局文件。
3. 安装全局内核和个人插件。
4. 启动全新任务验证发现、路由和降级行为。
5. 演练回退。

门禁：

- 用户确认行为符合预期。
- 其他项目与现有插件不受影响。
- 安装和回退证据被记录。

验收记录：

- 用户授权后执行真实全局安装，安装前 `AGENTS.md` 和 `config.toml` 均进入事务备份。
- 初始真实安装事务 `20260730T053748Z-ed636ad7` 的 status 与 doctor 健康。
- 5 个全新 ephemeral、read-only canary 全部正确发现全局规则和对应 Skill。
- 真实 rollback 后，`AGENTS.md` 与 `config.toml` 的 SHA-256 均与安装前完全一致。
- rollback 移除 Harness Plugin、marketplace 与 active state，其他 9 个 Plugin 集合保持不变。
- 最终通过新事务 `20260730T054043Z-fe9daceb` 重新安装。
- 最终 status、doctor 和重新安装后的新任务 canary 全部通过。

## 阶段 5：观察与演进

状态：进行中。

- 从真实任务收集摩擦，而不是预先增加规则。
- 一次只改变一个承重假设。
- 通过评测决定保留、修改或删除规则。
- 核心不变量变更继续要求用户批准。
