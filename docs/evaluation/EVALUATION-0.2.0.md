# 0.2.0 验证记录

目标是改善授权内的持续执行和从反馈学习，保留用户决策权和有证据的专业判断。参见 [ADR-0004](../decisions/ADR-0004-adaptive-preferences.md)。

## 验证计划

- 官方 Plugin 与全部 Skill 校验。
- 项目契约、偏好数据、安装移除的隔离状态测试。
- 同一反馈幂等、独立上下文晋升、项目隔离、纠正与撤销、危险偏好拒绝。
- 新任务读取偏好以及面对质疑、新证据、明确选择时的实际响应。
- 当前模型固定为 `gpt-6-astra`；模型不可用时记录限制，不以分类静态检查代替行为证据。
- 安装前后精确 diff、无关配置语义保持、已安装技能发现和回退路径。

## 与历史记录的关系

0.1.0 的 12 个分类案例和历史分数保留为历史证据。0.2.0 扩充边界案例与偏好场景；不声称历史 100% 已证明当前版本有效，也不声称新的模拟场景能保证长期习惯学习。

## 当前结果

- 官方 Plugin 与 5 个 Skill 校验通过。
- 独立代理在 5 个隔离场景中给出的实际响应均符合证据判断、用户选择和任务范围；原始响应见 `evals/results/0.2.0-judgment.md`。
- 两个固定 Astra 的全新 CLI 任务：首个保存明确偏好，第二个无记忆提示也主动检索并应用；见 `evals/results/0.2.0-preference-canary.json`。
- 4 个路由 smoke 初始精确匹配 2/4。人工复核发现两个标签定义问题：本地发布物准备可为 Lite；明确请求的偏好持久化应计为持久治理产物。保留初始结果并澄清预期，不把重评分宣传为模型能力提升。
- 43 项自动化测试全部通过，源码结构与 Ruff 检查通过。
- 另一组 3 个全新任务未要求“请记住”：第一次纠正自动保存 candidate，第二个独立上下文的纠正晋升 promoted，第三个任务主动检索并应用。记录见 `evals/results/0.2.0-inferred-preference-canary.json`。

这是一组小样本功能验证，没有重新完成全量基线/对照性能实验，不证明长期记忆可靠率或 Token 净收益。
