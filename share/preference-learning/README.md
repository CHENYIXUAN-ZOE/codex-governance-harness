# Codex 个人偏好学习包 · 0.2.0

让 Codex 从自然交流和重复纠正中学习你的工作习惯，并在后续任务中读取、修正这些记忆。你不需要逐条编写偏好规则。

## 怎么用

解压本包，把解压后的文件夹交给你自己的 Codex，发送下面这段话：

> 请阅读这个文件夹里的 INSTALL_FOR_CODEX.md，检查兼容性后，为我的 Codex 安装个人偏好学习机制。我授权你备份并局部合并所需的全局指令和技能；今后可以从我的自然反馈中自动保存、修正低风险的交流、输出和工作方式偏好，不必每次再问。不要导入别人的个人记忆，不要修改模型、账号、权限或其他无关配置。安装后验证，并告诉我保存位置和撤销方式。

如果 Codex 不能读取附件，请把压缩包解压到本机文件夹，再让 Codex 打开该文件夹。安装完成后新建一个任务使用。

## 它会做什么

- 一次有意义的纠正形成候选偏好；不同任务中的重复纠正增强可信度。
- 明确表达的长期习惯可以直接记录，临时要求不会自动变成永久规则。
- 区分全局和项目范围，新任务读取相关记忆；当前要求和项目事实优先。
- 允许查看、纠正、停用偏好，以及撤销最近一次记忆更新。

你可以自然地说：“你现在记住了哪些习惯？”“这个要求只适用于这个项目。”“这个偏好理解错了。”“撤销上次记忆更新。”

## 包含什么

本包只含通用学习技能、存储脚本、少量全局入口、安装说明和隔离自检工具。**不含制作者的个人偏好、聊天记录、项目数据、账号凭据或完整全局配置。** 技能里的示例只是示例，不会安装为你的偏好。

默认本地记忆位置：`~/.codex/governance-harness/preferences.json`；设置了 `CODEX_HOME` 时跟随该目录。第一次成功学习时才创建数据文件。安装会与现有配置局部合并，不要求安装完整 Governance Harness。

## 兼容性与边界

- 适用于能读写本机文件、运行 Python 的 Codex。存储脚本要求 Python 3.9+、macOS 或 Linux；Windows 需在 WSL 中运行 Codex 和 Python，原生 Windows 未支持。
- 不需要 API Key、额外 Python 包、MCP、数据库服务或后台监听。
- 这是“规则引导 + 本地记忆”，不是模型训练。需要 Codex 实际调用技能，不能保证每次都正确识别或永不遗漏。
- 停用一条偏好会保留记录，卸载技能也默认保留记忆；这两者都不等于删除数据。

## 验证和卸载

`python3 -B verify_bundle.py` 会校验文件并在临时目录验证存储、重复反馈和撤销，不会读取或修改你的真实偏好。

安装、验收、停止学习和卸载方法见 [INSTALL_FOR_CODEX.md](INSTALL_FOR_CODEX.md)。
