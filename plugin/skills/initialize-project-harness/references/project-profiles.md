# Project profiles

Governance intensity and project domain are separate.

## Intensity

- Lite: no persistent Harness by default.
- Standard: authority map, completion checks, and recoverable state when needed.
- Assured: risk, authorization, rollback, and stronger evidence.

## Composable domain modules

Select only modules with real requirements:

- software: build, test, architecture, release;
- data: sources, schema, reproducibility, reconciliation;
- research: evidence, citations, uncertainty, reproducible method;
- documents and content: audience, source authority, review, render verification;
- automation and agents: tool permissions, state, retries, stopping conditions, evaluation;
- external operations: system ownership, side effects, read-back confirmation;
- regulated or sensitive: privacy, access, retention, approval, audit evidence.

Do not create a cross-product of fixed templates. Compose the minimum relevant controls.
